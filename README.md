# S.I.M.A.S. — Sistema Inteligente de Monitoreo Ambiental y Seguridad

Sitio estático para GitHub Pages. El archivo `index.html` es autocontenido: incluye CSS, JavaScript, catálogo de 50 pistas e ilustraciones.

## Publicación
Seguí `TUTORIAL_GITHUB_PAGES.txt`. Para GitHub Free, usá un repositorio público y publicá desde `main` / raíz.

## Importante
GitHub Pages publica archivos estáticos. No ejecuta el servidor local de SIMAS ni transmite automáticamente las lecturas del Arduino a otros dispositivos. Para el panel receptor en vivo de una misma red, usá el servidor incluido en el paquete USB.
